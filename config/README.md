# Agent configuration

Keep selected agent configuration here. Shared prose belongs in
`instructions/AGENTS.md`; reusable workflows belong in `skills/`.

For Cursor, paste `cursor/user-rule.md` into a global User Rule in
Customize → Rules. The installer links skills into Cursor's personal skills
directory. It does not change Cursor settings.

The installer currently installs instructions and skills, plus executable
scripts. Add explicit mappings to `install.sh` when adding other configuration.
